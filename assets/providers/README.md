# Provider marks

These icons are bundled from the providers’ own websites so setup screens and
routing diagrams do not depend on remote image requests. They identify their
respective providers; they are not covered by the Simple Icons CC0 attribution.
Provider names and marks remain their owners’ trademarks.

`sources.json` records each original URL. PNG files preserve the source favicon
artwork, converted from the provider’s ICO/WebP assets where necessary. The web
panel embeds these PNGs in its existing SVG logo tiles.
