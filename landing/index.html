03Tako Code · new

One task.
A swarm of agents.

Describe a change in your Tako web panel. Tako Code, a small app on your PC, splits it up and runs several coding agents at once, each in its own Git worktree. It then merges their work, runs your tests and reviews the result. Nothing touches your branch until you apply it.

  1. Pick Claude Code, Codex, OpenCode or the built-in agent.
  2. Run 1–6 agents in parallel on your own machine.
  3. Route every request through your VPS to free models only.

06Good to know

Before you dive in.

Does Tako give me free AI access?

Tako routes through your provider accounts and local models. Some providers offer free tiers, but their limits and terms still apply. Tako doesn't bypass quotas or supply model credits.

Where do my keys and prompts go?

Provider keys stay in your Tako configuration on the machine running it. Prompts go to the providers you configure, according to your fallback order. Tako is a router, so your providers' data policies still apply.

Does Tako Code give me free Claude or Codex?

No. Claude Code and Codex are the agent apps; the models behind them come from the free providers you connect to your Tako server. Tako Code only uses free routes and never falls back to paid models, but provider quotas and account rules still apply. Agents run on your PC, and your code is sent to those providers.

Can I run it on a server?

Yes. Set an admin password, put Tako behind an HTTPS reverse proxy, and create separate client keys in the web panel. The repository includes Caddy and systemd examples.

Can I move my setup to another machine?

Yes. Open Connect in the web panel to export and import settings, or use tako export settings.json and tako import settings.json. Exports include provider API keys, so transfer them privately. Each machine keeps its own address and login security.

How do updates work?

Run tako update whenever you like. Or opt into daily verified updates with tako auto-update on. It restarts a running router when a newer release is installed; active requests can be interrupted. Turn it off with tako auto-update off.
